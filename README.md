# CompetitiveProgramming-SOC2026
This repo contains all the work done during first 4 weeks of the project on Competitive Programming conducted under Summer of Code 2026.

Below is the list of all topics covered as of now. Each week resources on these topics were provided by the mentors and after we had gone through the topics, mentors conducted a contest on codeforces, typically containing more than 10 questions, for a good practice and grasp on those concepts.
The codes that I wrote to solve those questions have been attached within each week, and additionally, whatever personal notes were taken related to topics or resources given, have been compiled into a pdf and attached separately.

## Week 1: Foundations, Complexity & Searching/Sorting
Topics: Time and space complexity (Big-O analysis, identifying bottlenecks, estimating operations per second), standard library mastery (vectors, sets, maps, pairs, sorting with custom comparators, binary_search, lower_bound, upper_bound), binary search on sorted arrays and binary search on the answer, two pointers (opposite ends and same direction), and sliding window technique (fixed-size and variable-size windows).
## Week 2: Greedy, Constructive & Math
Topics: Greedy algorithms (interval scheduling, activity selection, exchange arguments to prove correctness), constructive problems (building valid outputs from patterns), GCD/LCM and the Euclidean algorithm, modular arithmetic (addition, multiplication, handling negatives), modular exponentiation (fast power), Sieve of Eratosthenes for prime generation, modular inverse using Fermat's little theorem, and basic combinatorics (factorials with mod, nCr computation).
## Week 3: Recursion, Backtracking & DP Introduction
Topics: Recursion fundamentals (base cases, recurrence relations, recursion trees), backtracking (subsets, permutations, N-Queens, combination generation with pruning), and 1D DP problems including coin change (minimum coins and number of ways), 0/1 knapsack, unbounded knapsack, and longest increasing subsequence. Cover both memoization (top-down with caching) and tabulation (bottom-up iterative) approaches, along with state and transition identification.
## Week 4: Advanced Dynamic Programming
Topics: 2D DP including longest common subsequence, edit distance, and grid-based path counting, partition DP (matrix chain multiplication style problems), bitmask DP for problems with small N (subset enumeration, traveling salesman), digit DP for counting numbers satisfying constraints, and DP on intervals. Focus on recognizing DP patterns quickly and defining states/transitions cleanly.
